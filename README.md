## 고객용 보증서 링크 (?v=...)

- 관리 화면의 `고객 링크 복사` 로 만든 링크를 고객에게 보내면, 고객은 **보증서 이미지와 저장·인쇄 버튼만** 보게 됩니다. 입력 화면은 보이지 않습니다.
- 링크에는 고객명·차종·차량번호·시공 품목·시공일·보증기간·시공 내용·관리 안내·직인 여부·매장 정보가 UTF-8 → Base64url 로 담깁니다. **고객 휴대폰 번호는 담지 않습니다.**
- 기본 관리 안내(5줄)와 기본 매장 정보는 링크에서 빼서 길이를 줄입니다. (김지희 님 카니발 보증서 기준 약 350자)
- `문자 앱` 으로 보내면 본문에 링크가 자동으로 들어갑니다.
